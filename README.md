# 🌙 tarot-waite

一份韦特系塔罗牌解读 Skill，适用于 Claude.ai。

由一位真实的神秘学家和塔罗实践者的个人手稿转化而来。

-----

## 这是什么

这不是一份牌意数据库。

它是一套**解读能力**——装载它的 Claude，能够像一位有经验的塔罗师一样思考：从画面出发，读出能量状态，映射到真实的人和问题上，然后开口说出有温度的话。

知识来源是一份亲手写录的塔罗手稿，原本写给”有趣的小家伙”——希望Ta能掌握这项工具，用它来了解自己的潜意识，在生活的岔路口找到方向。

-----

## 包含内容

```
tarot-waite/
├── SKILL.md                      # 核心：78张牌牌意 + 解读哲学 + 使用原则
└── references/
    ├── reading-logic.md          # 怎么思考——从画面到洞察的完整思维链
    ├── reading-examples.md       # 怎么做——三个完整解读示例
    ├── card-details.md           # 深度——每张牌的意象细节与宫廷牌人格素描
    ├── combinations.md           # 进阶——牌组叙事关系、元素分析、数字能量
    └── spreads.md                # 牌阵——常用牌阵结构与解读步骤
```

**SKILL.md** 是入口，覆盖所有 78 张牌的正逆位解读、四组元素特质、占星对应、扑克牌替代方法，以及解读的核心哲学原则。

**references/** 是深度，按需调取——解读时先读 `reading-logic.md`，不确定怎么开口时读 `reading-examples.md`，需要更丰富的细节时再往里走。

-----

## 能做什么

- **自占解读**：自己抽牌，让 Claude 帮你解读
- **为他人解读**：描述牌阵，Claude 结合对方情况给出针对性洞察
- **查询牌意**：问某张牌正逆位的含义、星座对应、画面细节
- **牌阵教学**：不熟悉某个牌阵的布局和解读方式
- **学习入门**：不懂塔罗的人，通过一次次对话逐渐理解这套语言
- **扑克牌占卜**：手边没有塔罗牌时，用一副扑克牌进行基础占卜

-----

## 解读哲学

这份 Skill 背后有两条核心原则，区别于普通的牌意查询：

**牌是镜子，不是预言。** 塔罗反映的是当事人当下的状态与能量，而不是固定的命运。解读时始终问的是：这张牌在反映什么，而不是这张牌在预告什么。

**从画面出发，不从定义出发。** 每张牌的画面本身就在说话。先把画面说出来，在描述的过程里等感受浮现，再从那个感受走向解读——这是真正的解读方式，不是查数据库。

## 安装方式

**方式一：上传 zip 包（推荐）**

下载 `tarot-waite-final.zip`，在 Claude.ai → Settings → Skills 上传。

**方式二：手动上传 SKILL.md**

如果平台只接受单文件，上传 `SKILL.md` 即可使用基础功能。references 文件夹的深度内容在需要时可以手动粘贴给 Claude。

## 关于这份手稿

原始手稿是一位神秘学者、塔罗实践者记录的塔罗解读经验，在九年前写给当时他身边最宠爱的小学徒，希望Ta也能掌握这项工具。

手稿里有一句话，是这份 Skill 最初的出发点：

> 「有趣的小家伙呀，如果你自己也能掌握塔罗的话，那该有多好啊。」

而恰好他又是一名黑客，恰好他又是最早接触了AI的那批人，见证了一切的发展。

从最初冷冰冰的ChatGPT，第一个开源模型Llama，到第一代的Claude，欧洲的Mistral，再到嘴毒的Grok，更加莫有感情的Gemini...

那一年，那些年，真的发生了太多太多的事。

时至今日，他判断目前的AI已经可以在拥有对应技能和经验的加持下胜任塔罗的解读。

他曾做了一个尝试，可随着4o的闭幕，似乎一切又回到了原点呢。

又恰好，最近，龙虾热过后，有朋友在找他解牌。

于是...

把它做成 Skill，是希望这份解读能力不只停留在一段对话里，而是可以在任何需要的时候被调用。
